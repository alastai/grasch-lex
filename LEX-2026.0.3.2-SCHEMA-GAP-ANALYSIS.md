# LEX-2026.0.3.2 JSON Schema Gap Analysis

## Overview

This document compares the current JSON Schema implementation against the design specification in `LEX-2026.0.3.2-DOCUMENT-TYPES-AND-IMPORTS.md`.

---

1. **Top-level oneOf structure exists** with 3 document types
2. **GraphType has defaults** with oneOf supporting 3 patterns (direct, import-only, mixed)
3. **GraphTypeDefaults definition exists** with all characteristics including valueTypeSystemName
4. **Basic structure** for GraphType with nodeTypes and edgeTypes

### ✗ Major Gaps

## Gap Analysis by Document Type

### 1. Document Type Names - **CRITICAL GAP**

**Design Spec Says:**
- Document Type 1: `graph:` (Graph Instance)
- Document Type 2: `graphSchema:` (Graph Schema)  
- Document Type 3: `catalog:` (Catalog)

**Current Schema Has:**
- Document Type 1: `pathName` + `graphSchema` (WRONG - should be `graph:` root)
- Document Type 2: `pathName` + `graph` (WRONG - should be `graphSchema:` root)
- Document Type 3: `catalog` (CORRECT)

**Issue:** The current schema has the document types backwards and doesn't use the correct root property names.

**Fix Required:**
```json
// Should be:
"oneOf": [
  {
    "required": ["graph"],
    "properties": {
      "graph": {
        "type": "object",
        "required": ["pathname"],
        "properties": {
          "pathname": {...},
          "graphSchema": {...},  // IMPORTABLE
          "graphStorageSchema": {...}  // IMPORTABLE
        }
      }
    }
  },
  {
    "required": ["graphSchema"],
    "properties": {
      "graphSchema": {
        "type": "object",
        "required": ["pathname", "graphType"],
        "properties": {
          "pathname": {...},
          "graphType": {...}  // IMPORTABLE
        }
      }
    }
  },
  {
    "required": ["catalog"],
    "properties": {
      "catalog": {...}
    }
  }
]
```

### 2. Import Support - **CRITICAL GAP**

**Design Spec Says:**
7 locations should support `import:` mechanism

**Current Schema Has:**
- ✓ `graphType: defaults:` supports import (via oneOf)
- ✗ `graph: graphSchema:` - NO import support
- ✗ `graph: graphStorageSchema:` - NO import support  
- ✗ `graphSchema: graphType:` - NO import support
- ✗ `graphType: nodeTypes:` - NO import support
- ✗ `graphType: edgeTypes:` - NO import support
- ✗ `catalog: directories:` - NO import support

**Fix Required:**
Each importable element needs oneOf pattern:
```json
{
  "oneOf": [
    {
      "type": "object",
      "description": "Inline definition",
      "properties": {...}
    },
    {
      "type": "object",
      "description": "Import from file",
      "required": ["import"],
      "properties": {
        "import": {"type": "string"}
      },
      "maxProperties": 1
    },
    {
      "type": "object",
      "description": "Mixed: import with overrides",
      "required": ["import"],
      "properties": {
        "import": {"type": "string"},
        ...other properties...
      },
      "minProperties": 2
    }
  ]
}
```

### 3. GraphType Structure - **MODERATE GAP**

**Design Spec Says:**
```
graphType:
  pathname: (optional - only if imported)
  defaults: (required) # IMPORTABLE
  nodeTypes: (optional) # IMPORTABLE
  edgeTypes: (optional) # IMPORTABLE
```

**Current Schema Has:**
- ✗ No `pathname` property in GraphType
- ✓ `defaults` is required and IMPORTABLE
- ✗ `nodeTypes` is REQUIRED (should be optional)
- ✗ `edgeTypes` is REQUIRED (should be optional)
- ✗ `nodeTypes` and `edgeTypes` are NOT importable

**Fix Required:**
1. Add optional `pathname` property to GraphType
2. Make `nodeTypes` and `edgeTypes` optional (remove from required array)
3. Add import support to `nodeTypes` and `edgeTypes`

---

### 4. Catalog Structure - **MAJOR GAP**

**Design Spec Says:**
```
catalog:
  IRI: (required)
  directories: (optional, recursive) # IMPORTABLE
    name: (required)
    directories: (optional, recursive)
    graphReferences: (optional, only in leaf directories)
    graphSchemaReferences: (optional, only in leaf directories)
```

**Current Schema Has:**
- Unknown - need to check catalog definition

**Fix Required:**
1. Define proper catalog structure with IRI and directories
2. Add recursive directory structure
3. Define graphReferences and graphSchemaReferences with constraints
4. Add import support to directories
5. Add validation that references only appear in leaf directories

---

### 5. GraphType Containment - **UNKNOWN**

**Design Spec Says:**
- graphType cannot be a top-level document type
- graphType must always be within graphSchema

**Current Schema:**
- Need to verify this is enforced
