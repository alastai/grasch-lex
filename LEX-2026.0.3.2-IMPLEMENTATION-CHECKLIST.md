# LEX-2026.0.3.2 Implementation Checklist

## Status: In Progress

This document tracks all changes needed to bring the implementation up to date with the 0.3.2 specification.

---

## 1. JSON Schema Updates

### Edge Type Schema Changes
- [ ] Remove `typeLabel` from edgeType (now in `via:`)
- [ ] Add `directed:` object with `from:`, `to:`, `via:` (or `arc:`)
- [ ] Add `undirected:` object with `between:`, `and:`, `via:` (or `arc:`)
- [ ] Add synonym support: `tail:`/`head:`, `src:`/`dst:`/`dest:`
- [ ] Add `SAME`/`SELF` as valid endpoint values
- [ ] Add validation: cannot mix synonym pairs (e.g., no `src:` + `head:`)
- [ ] Make `implies:` optional when no properties/labels
- [ ] Support inline node type definitions in endpoints

### Node Type Schema Changes
- [ ] Add `final:` wrapper for node types
- [ ] Add `sealed:` wrapper for node type hierarchies
- [ ] Add `abstract:` and `abstractSupertype:` as synonyms
- [ ] Support singleton supertypes as string (not just array)
- [ ] Support `extends:` and `supertypes:` as synonyms
- [ ] Add `adding:` block for incremental type definition

### Validation Rules
- [ ] Validate: `final:` types cannot be subtyped
- [ ] Validate: `sealed:` hierarchies are closed
- [ ] Validate: `abstract:` interpretation + all `final:` = INVALID
- [ ] Validate: `abstract:` interpretation + all `sealed:` = INVALID
- [ ] Validate: synonym pairs not mixed in edge types
- [ ] Validate: `via:` or `arc:` required unless anonymous edge
